# Dealline

Web-Programm von W Software (mert.win/deal): Deals mit anderen festhalten – worum es geht, wer mitmacht, wer was macht,
Regeln für alle und für einzelne Mitglieder – und als PDF oder Bild herunterladen.

Lizenz: Apache-2.0

`vorlage/` enthält eine bestehende W-Software-Webseite (QR-Gestalter) als Stil-Vorbild sowie `acryl.css` und `mobile.css`.
